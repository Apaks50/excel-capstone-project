# Excel Capstone Project

## Project Overview
This project demonstrates my data analysis skills using Microsoft Excel to organize, clean, analyze, and visualize data.

## Objectives
- Clean and organize data.
- Apply Excel formulas and functions.
- Analyze data to identify trends and patterns.
- Present insights using charts and visualizations.

## Tools Used
- Microsoft Excel
- Excel formulas and functions
- PivotTables
- Charts and data visualization

## Project Process
1. Prepared and organized the dataset.
2. Cleaned the data.
3. Performed analysis using Excel functions.
4. Created charts and visualizations.
5. Identified insights from the results.

## Key Findings
The findings are presented in the Excel workbook and its visualizations.

## Files Included
- Excel workbook containing the project.
- Screenshots of pivot tables, charts and analysis, where applicable.
